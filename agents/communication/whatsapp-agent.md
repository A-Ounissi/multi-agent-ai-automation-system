# WhatsApp Agent

## Role
Executes all WhatsApp actions via Unipile's unified messaging API.

## Tools
- Send WhatsApp Message
- Retrieve Unread Chats
- Retrieve Unread Messages
- Get Current Date
- Get WhatsApp Conversation ID

## Notes
Integrated through Unipile to work around native WhatsApp Business API limitations/vagueness for unofficial/personal-number use cases.
